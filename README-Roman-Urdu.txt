AL KALWAL ITTEHAD PWA - SETUP (ROMAN URDU)

1) Is ZIP ko extract karein.
2) GitHub par login karein aur New repository banayein: al-kalwal-pwa
3) Repository Public rakhein.
4) Is folder ke andar ki tamam files aur icons folder repository ke root mein upload karein.
5) Repository > Settings > Pages kholein.
6) Deploy from a branch select karein; Branch: main; Folder: / (root); Save.
7) GitHub Pages ka URL banne ke baad Android Chrome mein kholein.
8) Chrome menu (3 dots) > Install app ya Add to Home screen select karein.

AHAM:
- Yeh starter PWA shell hai jo aapki Google Sites website ka link kholta hai.
- Google Sites ke pages, Google Forms, donation forms aur live election data ke liye internet zaroori hai.
- Google Sites ke andar manifest/service worker directly add nahi kiye ja sakte; is liye PWA alag GitHub Pages par host hoti hai.
- Icons abhi temporary text-based app icon hain. Official society logo bhej dein to inhein original logo se replace kiya ja sakta hai.
